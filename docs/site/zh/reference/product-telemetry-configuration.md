# 配置规模分桶

产品使用遥测会将配置数量分桶附加到真实产品活动。配置加载、目录刷新和空闲定时器本身不会产生活动或创建安装身份。收集遵循[遥测控制](/zh/commands/telemetry)。

## 测量内容

只有已启动的聚合运行时会观测这些数量；普通 CLI 配置读取不贡献观测。

`servers` 在配置成功加载或重新加载时统计通过验证的静态服务器定义与已声明的模板定义，包括已禁用定义。无论创建多少实例，每个模板定义只计一次。同名时模板定义优先，该目标只计一次。该指标表示配置定义数量，不代表已连接或已启用的后端数量。加载失败或定义验证不完整时，不产生新的服务器数量观测。

`tools` 统计所获取运行时能力目录中已接纳的外部工具路由，排除内部工具和已禁用的源工具。它反映所选目录和已观测的模板实例，不代表所有配置后端的潜在工具总量。断开、不可用、未实例化、被拒绝或超时的来源会限制覆盖范围。不同客户端选择可能得到不同数量。遥测不会额外请求后端。

只有这些数字进入观测接口；名称、Schema、标签、预设、URL、配置值及运行时和会话标识均不导出。

## 分桶与变化

| 数量       | 导出的分桶 |
| ---------- | ---------- |
| 0          | `0`        |
| 1          | `1`        |
| 2–5        | `2-5`      |
| 6–20       | `6-20`     |
| 21–100     | `21-100`   |
| 101 及以上 | `101+`     |

只接受非负安全整数。零表示观测到数量为零；没有观测表示覆盖情况未知。

每个进程为每项测量保留最新快照，即使数量下降也会替换此前快照。下一次获准的真实活动只消费该快照一次。活动前的重复刷新合并为一次观测；若刷新后分别发生真实活动，则可能重复观测。因此它表示观测频次，不代表安装总量、当前全量清单或 UTC 周期最大值。UTC 报告按消费快照的活动时间归属观测日期，即使快照在 UTC 午夜前已取得。配置或选择变化时，同一安装可能出现在多个分桶。

## 共享身份与报告限制

多个运行时作用域共享本地安装身份。服务按身份去重安装活动，不会将各作用域相加作为安装数量。分桶指标累加观测次数；不会合并跨作用域的工具、选取每个安装的最大值，或统计每个分桶的独立安装数。不能通过累加分桶观测次数估算安装量。重置可能产生新身份；禁用会清除未发送的观测，已发送的数据无法撤回。

人工活动与显式启用的 CI 活动分开统计。普通自动化测试始终排除在外。尽力交付、不完整目录、重置及缺失活动都会限制覆盖范围。私有报告中的配置行展示测量名称、分桶及观测次数，无法据此还原客户配置。
