# 隐私与产品使用遥测

1MCP 通过产品使用遥测了解安装活跃情况、版本和平台采用情况，以及哪些命令和功能需要改进。**除 CI 和测试外，收集默认开启。** 首次收集前，1MCP 会向标准错误输出提示和关闭命令，不会将提示写入 MCP 标准输出。

## 关闭收集

关闭当前操作系统用户的本地安装遥测，包括正在运行的运行时：

```bash
1mcp telemetry disable
1mcp telemetry status
```

保存的偏好适用于本地各项目和运行时作用域。关闭会清除尚未发送的汇总，保留已有安装标识。在文件系统正常工作时，运行中的运行时会在五秒内观察到变更。已经传输的请求无法撤回。

仅抑制一次执行时，使用 `--product-telemetry=false` 或设置 `ONE_MCP_PRODUCT_TELEMETRY=false`。`DO_NOT_TRACK=1` 同样会抑制收集。保存的关闭偏好和进程级关闭设置均优先于开启设置。CI 默认关闭，须显式选择加入；测试拥有的执行始终被抑制。帮助、版本及 `telemetry` 控制命令不收集使用数据，也不创建安装标识。

即使选择远程运行时，这些控制也只作用于本地。远程运行时遵循其所有者的偏好；请向其运营者了解收集设置。关闭产品使用遥测不会改变运行时诊断日志或运行遥测的设置。

## 发送哪些数据

客户端通过 HTTPS 向第一方端点 `https://ingest.1mcp.app/v1/summaries` 发送大小受限、在本地聚合的汇总。字段由版本化客户端代码固定；服务不能向客户端下载扩大收集范围的策略。

| 数据       | 包含的信息                                                                        |
| ---------- | --------------------------------------------------------------------------------- |
| 安装和传输 | 随机安装 UUID 和随机批次 UUID                                                     |
| 活动时间   | 精确到秒的活动时间戳；计数在 UTC 日内聚合                                         |
| 产品和平台 | 1MCP 版本、操作系统类别、架构、Node.js 主版本及 CI 分类                           |
| 使用计数   | 固定的命令、功能和 MCP 操作类别，以及粗粒度成功或失败结果                         |
| 连接类别   | 运行时入口传输方式及固定客户端类别：Claude、Codex、Cursor、VS Code、other 或 none |
| 配置规模   | 服务器或工具数量分桶：0、1、2–5、6–20、21–100 或 101+                             |

汇总**不包含提示词、工具参数和结果、资源内容、凭据、路径、URL、IP 地址、请求头、原始错误、环境快照，以及任意后端、工具、客户端、预设或标签名称**。也不包含运行时、运行时作用域和会话标识、诊断指纹或追踪关联信息。未知客户端记为 `other`，不会发送其提供的名称和版本。

随机安装标识属于**假名化标识，并非匿名数据**：服务可以据此关联同一本地安装随时间产生的汇总。它不是账号标识或硬件指纹。与任何 HTTPS 连接一样，接收端网络基础设施可以观察到源 IP 等连接元数据；汇总中不含 IP 地址，并不意味着连接匿名。

## 本地存储与重置

当前操作系统用户的各本地运行时作用域共用一个私有存储：macOS/Linux 为 `~/.config/1mcp/product-telemetry`，Windows 为 `~/AppData/Roaming/1mcp/product-telemetry`。其中保存偏好、提示状态、随机标识及尚未发送的汇总。客户端要求 POSIX 文件仅所有者可访问，Windows 使用受保护的当前用户 ACL。无法验证这些保护时，收集会被抑制。

未发送队列最多占用 256 KiB。汇总在七天后过期；过期或最早的条目会被丢弃以满足上限。传输尽力而为，绝不延迟 MCP 请求、命令完成、就绪或关闭。离线、短命令和失败的发送尝试都可能造成测量丢失。

```bash
1mcp telemetry reset   # 清除本地标识及未发送汇总，保留已保存的偏好
1mcp telemetry enable # 允许后续活动收集，但其他关闭设置仍然有效
```

重置本身不会创建替代标识；之后一次允许收集的活动才会创建新标识。关闭再开启会保留已有标识。**重置不会删除服务已经收到的记录。** 若希望重置后仍关闭收集，请保持已保存的偏好为关闭。

## 服务保留期限与访问

服务策略规定：

- 详细汇总在 90 天后过期。
- 与安装关联的同期群历史最多保留 12 个月。
- 不活跃的服务端身份在 12 个月后过期。
- 不含安装 UUID 的每日总量可以无限期保留。

这些期限不会使本地标识过期；本地标识保留到显式重置为止。报表描述近似的安装活动，不代表人数。显式启用的 CI 活动与主要安装和留存指标分开报告。

服务设计使用 1MCP 拥有的 Cloudflare Worker/D1 基础设施，不向分析供应商转发汇总。聚合仪表盘仅维护者可访问，不提供按安装钻取。收集器公开、访问保护及保留策略执行属于服务发布要求；本客户端文档并不能证明线上部署已经满足这些要求。客户端实现可在 [1MCP 仓库](https://github.com/1mcp-app/agent/tree/main/src/productTelemetry) 中查看。

完整选项优先级和排障说明见 [telemetry 命令](/zh/commands/telemetry)。类别定义见 [命令及 Admin 采用情况](/zh/reference/product-telemetry-adoption)、[MCP 操作](/zh/reference/product-telemetry-operations)和[配置分桶](/zh/reference/product-telemetry-configuration)。
