# Duplicate OAuth Refresh-Token Record

This record preserves the history of an accidentally duplicated OAuth refresh-token ADR that was previously assigned a second `0011` identifier. Its duplicated decision text is intentionally not retained here.

The canonical decision is [ADR 0014: OAuth Refresh Tokens Use Rotating Families](0014-oauth-refresh-tokens-use-rotating-families.md). It is the sole authoritative decision for refresh-token rotation and replay handling.
