# 1MCP Agent - 中文文档

1MCP 将多个 MCP 服务器聚合到统一运行时。中文文档使用 `/zh/` 规范路由。

## 从这里开始

- [安装](/zh/guide/installation)：通过 npm、发布归档或 Docker 安装。
- [快速开始](/zh/guide/quick-start)：配置服务器并验证首次运行。
- [入门指南](/zh/guide/getting-started)：选择安装、身份验证或部署路径。
- [基础配置](/zh/guide/essentials/configuration)：将 MCP 清单保存在 `mcp.json`，运行时设置保存在 `config.toml`。
- [CLI 模式](/zh/guide/integrations/cli-mode)：面向 agent 会话的渐进式服务器和工具发现。

## Agent 工作流

每个客户端只能选择一种面向 agent 的集成模式。CLI 模式使用 `1mcp cli-setup --codex` 或 `1mcp cli-setup --claude`；该命令会打印所需的本地配置修改。

1. 运行 `1mcp instructions` 获取当前 playbook 和服务器清单。
2. 选择工具前运行 `1mcp inspect <server>`，再运行 `1mcp inspect <server>/<tool>`。
3. 确认工具 schema 后才运行 `1mcp run <server>/<tool> --args '<json>'`。
