# 1MCP Agent - English Documentation

1MCP aggregates MCP servers behind one runtime. English documentation is served from root routes.

## Start Here

- [Installation](/guide/installation): Install from npm, a released archive, or Docker.
- [Quick Start](/guide/quick-start): Configure a server and verify a first runtime.
- [Getting Started](/guide/getting-started): Choose an installation, authentication, or deployment path.
- [Configuration](/guide/essentials/configuration): Keep MCP inventory in `mcp.json` and runtime settings in `config.toml`.
- [CLI Mode](/guide/integrations/cli-mode): Progressive server and tool discovery for agent sessions.

## Agent Workflow

Use one agent-facing integration mode per client. For CLI mode, run `1mcp cli-setup --codex` or `1mcp cli-setup --claude`; it prints any required local configuration changes.

1. Run `1mcp instructions` to obtain the current playbook and server inventory.
2. Run `1mcp inspect <server>` and then `1mcp inspect <server>/<tool>` before selecting a tool.
3. Run `1mcp run <server>/<tool> --args '<json>'` only after confirming the tool schema.
