# 后端日志

在 Admin Console 中打开 **Logs**，可以查看托管 stdio 后端输出到 stderr 的内容。每个已配置服务器或模板实例都有独立的日志源。当前选中的日志源会实时更新；未选中的日志源只增加未读计数，不会在后台渲染日志内容。

运行时只采集由自身管理的 stderr：包括默认 stdio 配置，以及托管的 `pipe` 或 Windows `overlapped` 目标。Stdio stdout 始终用于 MCP 协议，不会作为日志处理。远程 HTTP 和 SSE 后端不在采集范围内。如果 stdio 服务器显式配置了非托管 stderr 目标，例如 `inherit`、`ignore` 或数字文件描述符，Admin Console 会将其标记为不可用，而不会覆盖原配置。

## 保留与隐私

后端日志是内存中的诊断视图，不是审计记录：

- 日志进入 Admin Console 或运行时日志记录器之前，会先清理密钥和终端控制序列；
- 原始 stderr 不会被保留；
- 每个日志源最多保留 1 MiB，整个运行时最多保留 32 MiB；
- 超限时先淘汰最旧的记录；如果重连位置已经被淘汰，界面会用最新快照替换旧视图；
- 聚合运行时重启后，历史记录会清空。

静态服务器在子进程替换或禁用后重新启用时，会保持同一个日志源。模板实例在自身被替换时也会保持日志源，但新建的模板实例会获得新的日志源。已结束的日志源只在仍有保留记录时继续显示。

Logs 工作区使用 Admin Console 的同一个 Admin Session。Session 过期或被撤销后，实时连接会终止。连接中断时，工作区会自动重连，并从仍然保留的最后一个序列继续，不会重复显示日志。
